# v1.4 Release Notes

## Changes since v1.3.2 (2026-01-30)
- Improved CBOR codec support.
- Improved INTEGER constraint handling for unsigned 64-bit and larger
  arbitrary-precision bounds, with optional `-finteger-native-type` fixed-width
  native storage and `-flong-size` target `long` selection.
- Time.h disambiguation on case-insensitive filesystems.
- Fixes for ANY OER/APER codec issues in PKIX.
